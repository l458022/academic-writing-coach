# 合法语料获取指南

> **为什么需要这份文档**：本项目长期缺**现代真实语料**（v0.6 只用了 4 篇真人 + 1 篇 AI），
> 而检测器的阈值必须用真实语料校准。但**网上公开的学生作文不等于可以随便用**——
> 版权归作者本人。这份文档列出**真正合法**的获取途径。

---

## ⛔ 先说不做什么

| 不做 | 原因 |
|---|---|
| 爬取网上公开的学生作文 | 「公开」≠「可授权使用」。学生作文**仍受版权保护**，作者从未同意被用于训练检测器 |
| 使用来源不明的「作文合集」 | 无法确认许可，可能是侵权转载 |
| 把语料提交进本仓库 | 多数语料是 **NC（非商业）** 或 **SA（相同方式共享）**，与本项目的 MIT 许可冲突 |

**本项目的书面承诺**（`test/corpus/README.md`）：
> **不使用**任何受版权保护的论文、学生作业或付费语料库。
> 本项目不做未授权内容复制，也不建立任何形式的比对库。

## ⚠️ 使用语料的三条硬规则

### 1. 语料只用于本地标定，不进 git

多数语料是 NC/SA 许可，与本项目的 MIT 冲突。SA 具有传染性，
一旦提交，整个项目的许可都会被拖走。

**正确做法**：把语料放在 `test/corpus/student/`（已被 `.gitignore` 排除），
标定出的**阈值数字**可以进仓库（数字是事实，不受版权保护），**语料本身不行**。

### 2. 这些语料只有「真人」一侧

ICNALE / ELLIPSE 全是**人写的**。检测器要**两类**样本才能标定：
- **真人一侧** → 用这些语料 ✅
- **AI 一侧** → **必须自己生成**（用 LLM 造，无版权问题）

两边都齐了才能算阈值。缺任何一边都标不出来。

### 3. 时代要一致

本项目踩过最贵的坑就是**时代偏差**：v0.4 用「19 世纪英文 vs 现代 AI」标定，
阈值对现代学生完全失效。

→ 真人语料和 AI 语料**必须同属一个时代**。ICNALE 是近年收集的，没问题；
但**不要**再混入 Gutenberg 公版文本（那是 19 世纪）。

## 拿到语料后怎么用

```bash
# 1. 把语料转成纯文本，放进（已被 gitignore 的）目录
#    文件名含 ai / AI 的记为 AI 样本，其余记为真人样本
test/corpus/student/
  ├── icnale_mys_001.txt     # 真人
  ├── icnale_mys_002.txt     # 真人
  └── my_ai_sample_01.txt    # AI（自己生成）

# 2. 跑重标定诊断
node test/corpus/recalibrate_modern.js

# 3. 确认改动没让回归变差
node test/corpus/evaluate.js
```

⚠️ 改阈值前先记下当前指标，便于回退——本项目曾因样本不足过度拟合，
把纯 AI 文本从 95 分压到 47 分。
