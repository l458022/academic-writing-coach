# 语料与检测器评估（test/corpus/）

本目录用于**用真实语料验证检测器**，是改进检测器的事实依据。

## 合规声明

| 来源 | 许可 | 说明 |
|---|---|---|
| `human/` | **公有领域** | 全部来自 Project Gutenberg，版权已过期 |
| `ai/` | 无版权争议 | 人工撰写以模拟 LLM 输出风格 |
| `ai_modern/` | 无版权争议 | 开发者撰写的现代 AI 样本（同话题对照） |
| `student/` | **视来源而定** | 现代真实语料，**不随仓库分发** |

**不使用**任何受版权保护的论文、学生作业或付费语料库。
本项目不做未授权内容复制，也不建立任何形式的比对库。

### ⚠️ 关于 `student/`：为什么不入库

该目录存放**现代真实语料**，用于校准检测器（项目长期最缺的就是这个）。
但它**不随仓库分发**，原因分两种：

- **真实学生作业**（如开发者本人及同学的课程作业）：属他人文稿，不适合公开；
- **第三方学术语料**（如 ELLIPSE、ICNALE）：多为 **NC（非商业）** 或 **SA（相同方式共享）**
  许可，与本项目的 MIT 冲突——SA 具有传染性，一旦提交会拖走整个项目的许可。

**合法获取途径见 [`合法语料获取指南.md`](./合法语料获取指南.md)**，内含
ELLIPSE 直链与 ICNALE 申请模板（该语料含**马来西亚大学生**，最贴近目标用户）。

要复现 v0.7 的重标定，把合法获取的真人语料放进 `student/`（文件名不含 `ai`）即可；
AI 一侧由仓库自带的 `ai_modern/` 提供。

## 目录

```
corpus/
├── fetch_human.py     # 抓取 Gutenberg 公版文本并切分为 180-420 词片段
├── make_ai.py         # 生成 AI 对照样本（覆盖多种 LLM 风格）
├── calibrate.js       # 用实测分布重标定各特征阈值与方向
├── evaluate.js        # 批量评估：混淆矩阵 / 漏报率 / 误报率 / 特征判别力
├── recalibrate_modern.js   # 现代语料重标定诊断（只报告，不自动改代码）
├── evaluate_modern.js      # 在真实现代语料上评估误报/漏报
├── 合法语料获取指南.md       # ★ 合法语料清单 + ICNALE 申请模板
├── human/             # 72 篇真人语料（公版学术论述，19 世纪）
│   └── _manifest.json
├── ai/                # 9 篇 AI 对照样本（v0.4 时代，人工模拟）
│   └── _manifest.json
├── ai_modern/         # 15 篇现代 AI 样本（开发者撰写，随仓库分发）
├── student/           # ⚠️ 不入库：现代真实语料（版权/许可限制，见下）
├── _report.json       # 最近一次评估结果
└── _calibration.json  # 最近一次标定数据
```

## 运行

```bash
python test/corpus/fetch_human.py    # 抓取公版语料（需联网）
python test/corpus/make_ai.py        # 生成 AI 样本
node   test/corpus/calibrate.js      # 重标定特征
node   test/corpus/evaluate.js       # 评估检测器
node   test/corpus/recalibrate_modern.js   # 现代语料重标定（需自备语料，见下）
```

### ⚠️ 关于 `student/` 目录（本仓库不包含）

`recalibrate_modern.js` 需要**现代**语料才能发现"时代偏差"。
本仓库**不包含**该目录——它原本装的是真实的学生课程作业，开源时已移除。

要复现 v0.6 的重标定，请自备语料放进 `test/corpus/student/`：

- 文件名含 `ai` / `AI` 的 `.txt` → AI 生成样本
- 其余 `.txt` → 真人写作样本
- 建议：真人 ≥4 篇、AI ≥1 篇，每篇 ≥150 词，且**同属一个时代**

该目录已被 `.gitignore` 排除，不会被误提交。

## 语料构成

**真人语料（72 段）** —— 选取标准是"接近学术论述文体"，而非小说：

| 书 | 作者 | 文体 | 段数 |
|---|---|---|---|
| On the Origin of Species | Darwin | 科学论述 | 12 |
| Discourse on the Method | Descartes | 哲学论证 | 12 |
| The Voyage of the Beagle | Darwin | 科学观察 | 12 |
| On Liberty | Mill | 社会论述 | 12 |
| The Prince | Machiavelli | 政治论述 | 12 |
| An Enquiry Concerning Human Understanding | Hume | 哲学论证 | 12 |

**AI 样本（9 篇）** —— 覆盖 6 类 LLM 典型输出风格：
学术摘要、技术文档（无套话）、商业报告、教育解释、改写文本、议论文。

## ⚠️ 已知的样本局限（必须承认）

1. **时代偏差**：真人语料是 19 世纪英文，与现代学生写作在句长、标点习惯上
   有明显差异（平均句长 37 词 vs AI 15 词）。这**放大了**句长类特征的区分度。
2. **领域偏差**：公版学术文 vs 现代 AI 文本，主题不同。
3. **AI 样本是我人工撰写的**，可能与真实 LLM 输出仍有差距。
4. 因此实测的"22% 漏报率"是**这个特定对照组**上的数字，不能直接外推到
   留学生作业场景。它的价值在于**暴露特征方向错误**，而非给出绝对性能。

## 关键历史结论

**v0.3 → v0.4 的修正**（首轮评估暴露）：

| 特征 | 原假设 | 实测结果 | 处理 |
|---|---|---|---|
| TTR | 人类 > AI（照搬论文） | AI 0.759 > 真人 0.579 | **反转方向** |
| hapax | 人类 > AI | AI 0.635 > 真人 0.436 | **反转方向** |
| 实词密度 | 人类 > AI | AI 0.714 > 真人 0.464 | **反转方向** |
| 标点（分号等） | 弱信号 | AI 全 0，真人 1.97 | **权重 0.08 → 0.16** |
| 句首多样性 | 中信号 | 重叠 0.800，几乎无区分 | **权重 0.10 → 0.08，改用虚词占比** |
| 套话密度 | 主判据（0.34） | AI 均分仅 14.9，5/9 零命中 | **权重 0.34 → 0.12** |

首轮评估：漏报 88.9% / 误报 11.1% → 修正后：**漏报 22.2% / 误报 0.0%**
